# Book Tracker

Book Tracker is a backend-focused application that allows users to organize their books, track their reading progress, and manage their reading experience.

## About

Book Tracker is a platform designed for readers to organize their personal library, track their reading progress, review books, and discover new titles.

The application allows users to manage their books and build a personalized reading experience.

## Features

### Implemented

- User creation
- Username and email validation
- Password hashing
- User data persistence with MySQL

### Planned

- User authentication with JWT
- Search books using an external API
- Personal library management
- Reading status:
  - Want to Read
  - Reading
  - Read
  - Dropped
- Book reviews and ratings
- User profiles
- Recommendations
